# Asset sources

- Fonts: Bebas Neue and JetBrains Mono (SIL Open Font License 1.1), embedded as WOFF2 via the @fontsource npm packages.
- Icons: Simple Icons (CC0) for Python, JavaScript, React, Next.js, Node.js, FastAPI, Tailwind CSS, PostgreSQL, MongoDB, Docker, Git, GitHub, Gemini, Devpost, Gmail.
- LinkedIn: not in the current Simple Icons release, so connect.svg uses a plain "in" lettermark. Swap in the official mark from LinkedIn brand guidelines if you want it exact.
