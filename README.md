#### 1. [Event Planner & Celebration Engine](https://github.com/Kunal77744/event-planner)
> **Rank #41 out of 51,356 participants** • [Live Application ➔](https://event-planner-ten-ruby.vercel.app/) • [Demo Video ➔](https://www.instagram.com/reel/De1OOSev9fz/)

- **Serverless Edge Architecture:** Deployed on Vercel with a single entrypoint (`api/index.py`) and global static edge distribution.
- **Enterprise-Grade Security:** Hardened with strict Content-Security-Policy (CSP), nosniff, frame protection (DENY), edge headers, and Pydantic markup/XSS input sanitization (Scored **98/100 in Security**).
- **Hardened GenAI Pipeline:** Powered by Google Gemini (`google-genai` SDK) configured with strict JSON schemas (`response_mime_type: "application/json"`). Implemented `<user_notes>` boundary tags to prevent prompt injection and jailbreaks.
- **Deterministic Separation:** Separated creative suggestion generation from mathematical/budget calculations (`planner.py`, `refine.py`) to guarantee zero numeric hallucinations.
- **Resilience & Testing:** LRU in-memory cache (`maxsize=128`) with automated offline fallback suggestions. Automated GitHub Actions CI pipeline with **25/25 passing tests in pytest** (Scored **100/100 in Testing & Efficiency**).

### 🛡️ Engineering Principles I Stand By

1. **Deterministic Logic Over Blind LLMs:** Always isolate financial, numerical, and date math in deterministic rule engines to guarantee zero hallucinations.
2. **Security by Design:** Enforce Content-Security-Policy (CSP), nosniff, frame protection, and boundary tagging against prompt injections on day one.
3. **Automated Testing & CI:** Code is only production-ready if verified with passing automated test suites (`pytest`, GitHub Actions).
4. **Performance & Caching:** Minimize external API latency using smart LRU caching and graceful offline fallback engines.
